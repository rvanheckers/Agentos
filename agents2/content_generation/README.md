# Content Generation Agents

AI-powered content creation and enhancement tools.

## Available Agents

### script_generator.py
- **Purpose**: Generate video scripts using AI
- **Usage**: `python script_generator.py '{"topic": "cooking tips", "duration": 60, "style": "casual"}'`

### social_post_generator.py
- **Purpose**: Create social media posts and captions
- **Usage**: `python social_post_generator.py '{"content": "video.mp4", "platform": "tiktok"}'`

### template_engine.py
- **Purpose**: Apply content templates and formatting
- **Usage**: `python template_engine.py '{"template": "intro", "data": {...}}'`

### external_ai_enhancer.py
- **Purpose**: Enhance content using external AI services
- **Usage**: `python external_ai_enhancer.py '{"content": "text", "enhancement": "grammar"}'`

## External Usage
Complete content generation pipeline accessible via JSON interface.
