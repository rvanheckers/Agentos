# Audio Processing Agents

Audio transcription and voice generation tools.

## Available Agents

### audio_transcriber.py
- **Purpose**: Transcribe audio to text using AI
- **Usage**: `python audio_transcriber.py '{"audio_path": "audio.mp3", "language": "nl"}'`

### voiceover_creator.py
- **Purpose**: Generate AI voiceovers from text
- **Usage**: `python voiceover_creator.py '{"text": "Hello world", "voice": "female", "language": "en"}'`

## External Usage
Audio processing pipeline for transcription and synthesis via JSON API.
